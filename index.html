Beállítások

A döntéseid a repód data/feedback.json fájljába mentődnek, ebből tanul a szkenner. Ehhez egy GitHub-token kell, ami csak ezen a telefonon tárolódik.

  1. Nyisd meg: github.com/settings/personal-access-tokens/new
  2. Repository access: Only select repositories, és válaszd ezt a repót
  3. Permissions → Contents: Read and write
  4. Generate token, majd másold be ide
